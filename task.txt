- **Минимальная iOS 26.0** (IPHONEOS_DEPLOYMENT_TARGET = 26.0). Используй современные API без fallback для старых версий и без лишних #available
- iPhone + iPad (адаптивный layout, NavigationSplitView на iPad)
- Современный стек: @Observable (Observation), async/await, actors, AsyncStream, Swift Testing (import Testing) для новых тестов
- SwiftUI для общего UI, UIKit/TextKit 2 (UITextView + NSTextContentStorage/NSTextLayoutManager, NSTextAttachment/NSTextAttachmentViewProvider) для редактора. Нативный TextEditor с AttributedString из iOS 26 оцени, но если он не покрывает таблицы, блоки кода и изображения, используй TextKit 2
- Liquid Glass (iOS 26): применяй нативно там, где уместно (тулбары, панель форматирования, плавающие кнопки через .glassEffect / стандартные контролы), сохраняя чёрный фон
- Bundle ID: com.notepad.app, Display Name: Notepad
- Проект генерируется через **XcodeGen** (project.yml), .xcodeproj в репозитории не хранится
- Зависимости только через Swift Package Manager, проверенные и совместимые с Swift 6 и iOS 26. Для подсветки кода выбери лучший вариант (Highlightr/highlight.js или Tree-sitter), кратко обоснуй в README. Если библиотека не собирается под Swift 6 strict concurrency, обойди это корректно (@preconcurrency и т.п.) или выбери другую
- Архитектура MVVM: Models / Services / ViewModels / Views / Editor / Utils
- Никакого мусорного кода, комментарии только там, где они нужны

# MARKDOWN-ФОРМАТ И РАСШИРЕНИЯ

CommonMark + GFM (таблицы, чекбоксы, зачёркивание). Чего нет в Markdown, сериализуй через HTML-теги, чтобы файл оставался валидным:

- Выравнивание: <div align="left|right|center|justify">...</div>, у каждого абзаца или блока своё
- Выделение маркером любых цветов: <mark style="background:#RRGGBB">текст</mark>
- Цвет текста: <span style="color:#RRGGBB">текст</span>
- Подчёркивание: <u>текст</u>
- Таблицы: GFM pipe tables
- Блоки кода: ```lang ... ```
- Изображения: ![alt](assets/file.jpg)

Требуется **lossless round-trip**: открыл .md, отредактировал, сохранил, ничего не потерялось. Напиши тесты на парсер и сериализатор.

# РЕДАКТОР (ГЛАВНАЯ ЧАСТЬ)

Живой WYSIWYG-редактор в стиле Notes (результат форматирования виден сразу), плюс переключатель режима "Исходник" для ручной правки .md.

Форматирование:
- Жирный, курсив, подчёркнутый, зачёркнутый, inline code
- Заголовки H1-H6, цитаты, горизонтальная линия
- Маркированные, нумерованные списки, чекбоксы (с анимацией), вложенные списки
- Ссылки (автодетект + ручная вставка)
- Выравнивание: по левому краю, по правому, по центру, по ширине, для каждого абзаца отдельно
- Цвет текста и выделение маркером: палитра минимум из 12 цветов + произвольный цвет (ColorPicker), возможность снять выделение
- Очистка форматирования

Код:
- Блоки кода с выбором языка (cpp, c, js, ts, json, php, python, swift, java, kotlin, go, rust, html, css, sql, bash, yaml, xml и все остальные, что поддерживает движок), автоопределение языка
- Подсветка синтаксиса в тёмной теме (уровня Xcode / VS Code Dark+), моноширинный шрифт, горизонтальная прокрутка или перенос, кнопка "Копировать", Tab-отступы

Таблицы:
- Вставка, добавление и удаление строк и столбцов, редактирование ячеек прямо в редакторе, выравнивание колонок, горизонтальный скролл для широких таблиц, корректная сериализация в GFM

Изображения:
- Вставка из галереи (PhotosPicker), камеры, Файлов и буфера обмена. Сжатие и downscale, масштабирование, тап для полноэкранного просмотра, удаление

Прочее:
- Панель форматирования над клавиатурой (как в Notes: кнопка "Aa" с popover, быстрые кнопки), горизонтально прокручиваемая
- Undo/Redo (включая вставленные объекты), поиск и замена в заметке, счётчик слов и символов
- Dynamic Type, VoiceOver, iPad с внешней клавиатурой и хоткеями (Cmd+B, Cmd+I, Cmd+U, Cmd+K, Cmd+F и т.д.)

# СБОРКА НА GITHUB ACTIONS

Создай `.github/workflows/build.yml`:
- runner: macos-latest
- шаги: checkout -> brew install xcodegen -> `xcodegen generate` -> resolve SPM -> `xcodebuild archive` (схема Notepad, sdk iphoneos, Release, `CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY=""`) -> ручная упаковка: Notepad.app в Payload/, `zip -r Notepad.ipa Payload` -> upload-artifact с именем Notepad-unsigned-ipa
- триггеры: push, pull_request, workflow_dispatch
- кеширование SPM
- отдельный job для тестов на симуляторе iOS 26 (имя устройства подбери из доступных через xcrun simctl list)
- опционально: релиз с .ipa при создании тега

IPA должна быть **неподписанной** (для AltStore, Sideloadly, TrollStore). Проверь структуру: Payload/Notepad.app, корректный Info.plist, иконки в Assets.xcassets.
